# 1. Дерево процессов — ptree.py

Файл `ptree.py` получает информацию о процессах непосредственно
из виртуальной файловой системы `/proc`.

Для каждого процесса определяются:

- PID;
- PPID;
- UID;
- состояние процесса;
- RSS.

В программу не используется команда `ps`.

Запуск:

```bash
python3 ptree.py
